# PlungePalz Places — Dev Infrastructure

AWS SAM template and deploy script for a **new, self-contained dev stack** in **us-east-1**.

This stack only creates new resources (`Places_*` tables/functions, `plungepalz-places-dev-*` everywhere else). It does not import or modify the unrelated live app in this account, and it does not use `backend/infrastructure/cloudformation.yaml` (us-east-2 prod placeholder).

## What it creates

### DynamoDB (PAY_PER_REQUEST)
- **Places_Places** — PK `place_id`, stream `NEW_AND_OLD_IMAGES`, GSIs: `status-ts-index`, `slug-index`, `h3-r7-index`, `h3-r5-index`, `h3-r4-index`
- **Places_Submissions** — PK `submission_id` only (no GSIs)

### Lambdas (Python 3.13)
Each function is packaged from `backend/lambda_functions/<Name>` (`sam build` installs that folder's `requirements.txt` when present). There is **no algoliasearch layer**.

| Function | Route | Auth | Layers |
|----------|-------|------|--------|
| Places_Search | `GET /search` | none | `places_common` |
| Places_GetByID | `GET /place/{place_id}` | none | `places_common` |
| Places_Submit | `POST /submit` | none | `places_common` |
| Places_SubmitAIAutofill | `POST /submit/ai_autofill` | **AWS_IAM** | `places_common` + `generate_place_with_ai` |
| Places_AdminReview | `POST /plungepalz_admin/review` | **AWS_IAM** | `places_common` |
| Places_AlgoliaSync | DynamoDB stream | n/a | `places_common` |

`Places_AlgoliaSync` is gated by `EnableAlgoliaSync` (default **`true`**). Set `false` to skip the function, role, log group, stream mapping, and DLQ.

### Layers
- **places_common** — `backend/lambda_layers/places_common` (no requirements; attach to all HTTP Lambdas + AlgoliaSync)
- **generate_place_with_ai** — `backend/lambda_layers/generate_place_with_ai` (**SubmitAIAutofill only**)

### API Gateway REST (`dev` stage)
- CORS origin parameter `AllowedOrigin` (default `http://localhost:3000`)
- Changing `AllowedOrigin` forces a new `AWS::ApiGateway::Deployment`: SAM hashes the swagger body before substituting `Fn::Sub` in Cors/GatewayResponses, so the template also puts the resolved origin in `BinaryMediaTypes` (vendor type `application/vnd.plungepalz.allowed-origin; origin=...`), which SAM does resolve before hashing
- OPTIONS preflight generated by SAM on every route
- GatewayResponses DEFAULT_4XX / DEFAULT_5XX include CORS headers
- Throttling: `/search` and `/submit` 5 rps / burst 10; `/submit/ai_autofill` **1 rps / burst 2**; stage default 10 rps / burst 20

### AlgoliaSync stream mapping
- Stream view: `NEW_AND_OLD_IMAGES`
- `BisectBatchOnFunctionError: true`
- `MaximumRetryAttempts: 3`
- OnFailure destination: SQS DLQ `plungepalz-places-dev-algolia-sync-dlq`

### IAM (least privilege, no fixed RoleName)
- **Search** — logs only
- **GetByID** — `GetItem` on Places_Places
- **Submit** — `PutItem`, `ConditionCheckItem`, `TransactWriteItems` on both tables
- **AdminReview** — `UpdateItem` on Places_Places
- **SubmitAIAutofill** — `GetItem` + `UpdateItem` on both tables
- **AlgoliaSync** — stream read on Places_Places stream; `sqs:SendMessage` to its DLQ

No SES/SNS. No `ssm:GetParameter`.

### Env vars

All HTTP functions:

- `TABLE_PLACES`, `TABLE_SUBMISSIONS` (`!Ref`)
- `CORS_ALLOWED_ORIGIN` (default `http://localhost:3000`)

Search + AlgoliaSync:

- `ALGOLIA_APP_ID` (NoEcho stack parameter)
- `ALGOLIA_INDEX_NAME` (parameter, default `places_dev`)

Search only: `ALGOLIA_SEARCH_API_KEY`  
AlgoliaSync only: `ALGOLIA_WRITE_API_KEY`

SubmitAIAutofill only:

- `GOOGLE_PLACES_API_KEY`
- `ANTHROPIC_PLUNGEPALZ_PLACES_AI_GENERATOR_API_KEY`
- `ANTHROPIC_MODEL` (default `claude-haiku-4-5-20251001`; env-file may also use `ANTHROPIC_MODEL_ID`)
- `ANTHROPIC_MAX_TOKENS` (default `1024`)

Secret **values** are NoEcho CloudFormation parameters. They are not SSM parameters, not template defaults, and not written to the committed `samconfig.toml`.

### Other
- Log groups, 14-day retention
- Cost-allocation tags `project=plungepalz-places`, `env=dev` on taggable resources
- Artifacts bucket `plungepalz-places-dev-artifacts-<account-id>` via stack `plungepalz-places-dev-artifacts` (block public, SSE, 30-day lifecycle)
- Template rule: `AWS::Region == us-east-1`

## Secrets handling

`deploy.sh --env-file PATH` parses **only** these names (never `source`s the file):

**Required**

```
ALGOLIA_APP_ID
ALGOLIA_SEARCH_API_KEY
ALGOLIA_WRITE_API_KEY
```

**Optional** (missing or `--skip-key` → empty NoEcho param; warning logs the key name only)

```
GOOGLE_PLACES_API_KEY
ANTHROPIC_PLUNGEPALZ_PLACES_AI_GENERATOR_API_KEY
```

Optional non-secret `ALLOWED_ORIGIN`: if set, passed as `AllowedOrigin` (exactly `*` is acceptable for **dev only**, or a single `http(s)://host[:port]` with no comma or trailing slash); if unset, `AllowedOrigin` is omitted so the stack keeps its current value.

The MVP deploy skips provider keys:

```bash
./deploy.sh --env-file /path/to/uncommitted/secrets.env \
  --skip-key GOOGLE_PLACES_API_KEY \
  --skip-key ANTHROPIC_PLUNGEPALZ_PLACES_AI_GENERATOR_API_KEY
```

With the Anthropic key empty, `POST /submit/ai_autofill` is expected to return **503** `not configured` (handled in backend code).

It writes a **mode-600** `samconfig.toml` under `mktemp -d /tmp/plungepalz-places-dev-XXXXXX` (outside the repo) and runs `sam deploy --config-file` against that file. A `trap cleanup EXIT` plus per-signal traps (`INT`→130, `TERM`→143, `HUP`→129) delete the temp dir. `cleanup` only removes the temp dir (idempotent via `CLEANUP_DONE`); it does not exit. Signals sent to the script PID alone stop the script with those statuses.

Do **not** put secret values in:

- this repo's `samconfig.toml` (non-secret defaults only)
- `deploy.sh` / `template.yaml` defaults
- the PR body

`.gitignore` covers `.aws-sam/`, `*.local.*`, `samconfig.local.toml`, `params*.json`, and env files.

## Deploy

Prerequisites: AWS CLI, SAM CLI, Python 3.13 (for layer/function builds), profile `plungepalz-dev` (or `AWS_PROFILE`) locked to **us-east-1**.

```bash
cd backend/infrastructure/dev
./deploy.sh --env-file /path/to/uncommitted/secrets.env \
  --skip-key GOOGLE_PLACES_API_KEY \
  --skip-key ANTHROPIC_PLUNGEPALZ_PLACES_AI_GENERATOR_API_KEY
```

`--env-file` is required (Algolia keys required). `--skip-key NAME` is repeatable and allowlisted to the two optional provider keys. `--yes` is accepted (non-interactive) but does not skip the env file. `--guided` is optional.

### Post-deploy

1. Apply Algolia index settings (from the repo root, after #4 is present):

```bash
python backend/scripts/algolia_index_settings.py
```

2. CORS check on `/search`:

```bash
API_URL=$(aws cloudformation describe-stacks \
  --stack-name plungepalz-places-dev \
  --region us-east-1 \
  --profile plungepalz-dev \
  --query "Stacks[0].Outputs[?OutputKey=='ApiBaseUrl'].OutputValue" \
  --output text)

curl -sD - -o /dev/null \
  -H "Origin: http://localhost:3000" \
  "$API_URL/search"

curl -sD - -o /dev/null \
  -X OPTIONS \
  -H "Origin: http://localhost:3000" \
  -H "Access-Control-Request-Method: GET" \
  "$API_URL/search"
```

IAM routes (`POST /plungepalz_admin/review`, `POST /submit/ai_autofill`) need SigV4. For review without SigV4, #4 ships `python backend/scripts/review_place.py` (direct DynamoDB).

## Validation

```bash
cd backend/infrastructure/dev
sam validate --lint --region us-east-1
cfn-lint template.yaml
shellcheck deploy.sh
sam build --region us-east-1
```

Confirm the built layer has anthropic (`ls .aws-sam/build/GeneratePlaceWithAILayer/python | grep anthropic`) and that `sam validate --debug --region us-east-1` lists OPTIONS on each route.

## Tear down

```bash
aws cloudformation delete-stack \
  --stack-name plungepalz-places-dev \
  --region us-east-1 \
  --profile plungepalz-dev

aws cloudformation wait stack-delete-complete \
  --stack-name plungepalz-places-dev \
  --region us-east-1 \
  --profile plungepalz-dev

aws cloudformation delete-stack \
  --stack-name plungepalz-places-dev-artifacts \
  --region us-east-1 \
  --profile plungepalz-dev
```

Tables are deleted with the stack (no Retain). Back up data first if needed.
